# Command reference

> Generated by `npm run docs` from `src/core/commands`. Do not edit by hand.

Every command is available as: an MCP tool (same name, plus optional `projectId`), `unicali exec <id> <name> '<json>'`,
`POST /api/projects/:id/commands {"command","args"}`, and `useEditor.getState().exec(name, args)` in the editor.

## `rename_project`

## `set_format`

**Set output format, frame rate and duration.** Change the canvas size, fps or scene duration. "format" picks a preset (9:16, 4:5, 1:1, 16:9, 16:9-4k, 9:16-4k); or pass width/height directly (even numbers). Changing the aspect ratio re-frames the camera on the first device unless reframe=false.

| Arg | Type | Required | Notes |
|---|---|---|---|
| `format` | `"9:16"` \| `"4:5"` \| `"1:1"` \| `"16:9"` \| `"16:9-4k"` \| `"9:16-4k"` |  |  |
| `width` | integer |  | ≥ 16, ≤ 7680 |
| `height` | integer |  | ≥ 16, ≤ 7680 |
| `fps` | `24` \| `25` \| `30` \| `50` \| `60` |  |  |
| `duration` | number |  | Seconds — ≥ 0.5, ≤ 120 |
| `reframe` | boolean |  | default `true` |

## `set_screen`

| Arg | Type | Required | Notes |
|---|---|---|---|
| `deviceId` | string |  |  |

| `fit` | `"cover"` \| `"contain"` \| `"fill"` |  |  |

| `panX` | number |  | ≥ -1, ≤ 1 |
| `panY` | number |  | ≥ -1, ≤ 1 |

## `set_camera`

**Set the base camera (orbit rig).** The camera orbits "target": yaw (deg, around Y; 0 = front), pitch (deg, + = above looking down), distance (world units), fov (vertical degrees; 20–35 looks product-like). This is the rest pose; camera motions and camera paths animate on top of / instead of it.

| Arg | Type | Required | Notes |
|---|---|---|---|
| `target` | [number, number, number] |  |  |
| `yaw` | number |  | ≥ -720, ≤ 720 |
| `pitch` | number |  | ≥ -89, ≤ 89 |
| `distance` | number |  | ≥ 0.2, ≤ 100 |
| `fov` | number |  | ≥ 5, ≤ 120 |

## `frame_device`

**Point the base camera at a device so it fills the frame.** Resets target and distance so the device occupies `fill` of the frame height (0.62 is a comfortable hero framing). Keeps yaw/pitch unless reset=true.

| Arg | Type | Required | Notes |
|---|---|---|---|
| `deviceId` | string |  |  |
| `fill` | number |  | ≥ 0.1, ≤ 1.5, default `0.62` |
| `reset` | boolean |  | Also reset yaw, pitch and fov to defaults — default `false` |

## `add_motion`

**Add a motion preset clip to the timeline.** Adds a preset (see catalog presets) as a live clip. Device presets target a device (default: first); camera presets always target the camera. Clips stack: entrance + floating + camera move is the typical recipe. The scene duration grows to fit. Returns clipId.

| Arg | Type | Required | Notes |
|---|---|---|---|
| `preset` | `"hero-reveal"` \| `"side-entrance"` \| `"fly-by"` \| `"hero-spin"` \| `"tilt"` \| `"floating"` \| `"push-in"` \| `"pull-out"` \| `"camera-orbit"` \| `"screen-focus"` | yes |  |
| `target` | string |  | Device id for device presets; ignored for camera presets |
| `start` | number |  | Seconds — ≥ 0, default `0` |
| `duration` | number |  | Seconds (default: preset default) — ≥ 0.1, ≤ 120 |
| `params` | object |  | default `{}` |

| Arg | Type | Required | Notes |

## `set_camera_path`

**Animate the camera through a list of waypoints (camera journey).** Writes keyframe tracks for the camera rig. Each waypoint may set yaw/pitch/distance/fov/target, or "focus" on a screen region (e.g. a button at x=0.5,y=0.85). Unset fields carry over from the previous waypoint (the first falls back to the camera rest pose). replace=true (default) clears previous camera keyframes; clearCameraMotions also removes camera preset clips so they do not add on top.

| Arg | Type | Required | Notes |
|---|---|---|---|
| `waypoints` | { time, yaw, pitch, distance, fov, target, focus, ease }[] | yes |  |
| `waypoints[].time` | number | yes | Seconds — ≥ 0 |
| `waypoints[].yaw` | number |  |  |
| `waypoints[].pitch` | number |  |  |
| `waypoints[].distance` | number |  |  |
| `waypoints[].fov` | number |  | ≥ 5, ≤ 120 |
| `waypoints[].target` | [number, number, number] |  |  |
| `waypoints[].focus` | { x, y, size, w, deviceId, face } |  | Frame a region of a device screen (UV from top-left). Overrides target/distance (and yaw/pitch when face>0). |
| `waypoints[].ease` | `"linear"` \| `"easeIn"` \| `"easeOut"` \| `"easeInOut"` \| `"product"` \| `"expoOut"` \| `"backOut"` \| `"spring"` |  | Interpolation from this waypoint to the next — default `"product"` |
| `replace` | boolean |  | default `true` |
| `clearCameraMotions` | boolean |  | default `true` |

## `apply_template`

**Replace the animation with a ready-made template.** Templates: app-launch (Hero reveal from below, gentle floating, slow push-in. The classic store-ad opener.); feature-zoom (Side entrance, then the camera dives into a feature on screen and returns.); orbit-showcase (A full hero spin while the camera arcs around — shows the hardware from every angle.); camera-journey (A keyframed camera path: wide three-quarter view → top of the screen → bottom → hero.). Clears existing motions and keyframes unless keepExisting=true. Sets the duration to the template length.

| Arg | Type | Required | Notes |
|---|---|---|---|
| `template` | `"app-launch"` \| `"feature-zoom"` \| `"orbit-showcase"` \| `"camera-journey"` | yes |  |
| `deviceId` | string |  |  |
| `keepExisting` | boolean |  | default `false` |
